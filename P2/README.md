#  Newsletter Subscription

## Project Overview

This project implements a newsletter subscription feature for the DEV@Deakin website. Users can enter their email address and subscribe to the newsletter. A welcome email is automatically sent to the subscriber after successful registration.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EmailJS
- Gmail
